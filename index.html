So, what is NebulaOS?

It's a Linux distribution built around the idea of making a good desktop for people who like making things.

NebulaOS isn't trying to reinvent Linux from scratch. It builds on existing open-source software and adds its own ideas, applications, and design.

It's still very much a work in progress. Things will break. Features will change. Some ideas probably won't survive.

Still being built.

NebulaOS is currently in development. The first releases are focused on getting the basics right before adding more features.

What are you waiting for?

NebulaOS isn't ready for a public release just yet.

Check the GitHub repository for development builds, source code, and future releases.
